# Source notes

## Identity reference

The user selected the supplied **15 / Morph** concept board. The upper-left symbol and wordmark served as the source for the SVG masters. The brand-manual reference guided the landscape layout, strong section dividers, logo diagrams, color specifications, and application examples.

## Contrast guidance

https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum

Ratios in the guide use the WCAG sRGB relative-luminance calculation. They apply to the listed foreground/background colors, not to an entire application's accessibility.

## Generated supporting artwork

The liquid editorial image and physical application image were created with the built-in image-generation tool using the selected Morph board as a reference. They show art direction and application intent. They do not depict existing merchandise or an actual event.

Liquid image direction: one continuous glossy obsidian form with neon #CCFF00 reflected light, broad elastic surfaces, dark negative space, and no text or logos.

Physical image direction: tactile black tote, neon notebook, cards, and lanyard in a daylight studio composition, using the selected connected Morph symbol and Hyperwood wordmark.
